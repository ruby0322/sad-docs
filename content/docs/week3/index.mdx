## 第三週：Version Control、Git 與 GitHub

本週聚焦**版本控制**與**團隊協作**：從安裝與設定開始，認識 Git 的核心概念與日常指令，學習分支策略與整合流程，並透過 GitHub 完成遠端儲存庫、Fork 與 Pull Request 等實務，為後續 [**第六週**](/docs/week6) 容器與 [**第十一週**](/docs/week11) DevOps 主題打好基礎。

> **CI／GitHub Actions** 安排在第十一週，與單元測試、Playwright 一併實作；本週 GitHub 章節僅涵蓋協作與 PR 流程。

## 課程大綱

1. [**環境與專案準備**](/docs/week3/getting-started)  
   - 必要工具與 Todo App（SADo）專案起步

2. [**Git**](/docs/week3/git)  
   - 版本控制概念與常用指令

3. [**分支策略**](/docs/week3/branch-strategy)  
   - Git Flow 範例、分支命名、`merge`／`rebase`、squash 與 GitHub 三種 PR 合併方式

4. [**GitHub**](/docs/week3/github)  
   - 遠端儲存庫、Fork、`upstream`、Pull Request 與 Code Review

## 學習目標

- 理解版本控制的目的與 Git 基本模型（commit、branch、merge）。  
- 能獨立完成 clone、branch、commit、push、pull 與處理簡單衝突。  
- 能說明並實作與課程一致的分支策略與 PR 流程。  
- 熟悉 GitHub 上議題、分支與 Code Review 的協作節奏。

## 注意事項

- 請依課程公告準備 GitHub 帳號；Fork 範例儲存庫時以助教提供的網址為準。  
- 若本機尚未安裝 Git 或設定使用者名稱／信箱，請先在 [環境與專案準備](/docs/week3/getting-started) 完成設定。
