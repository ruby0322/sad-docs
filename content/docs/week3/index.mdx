## 第三週：Version Control、Git 與 GitHub

本週聚焦**版本控制**與**團隊協作**：從安裝與設定開始，认识 Git 的核心概念與日常指令，並透過 GitHub 進行遠端儲存庫、分支與 Pull Request 等實務流程，為後續容器與 DevOps 主題打好基礎。

### 課程文件導覽

1. [**環境與專案準備**](/docs/week3/getting-started)：工具與 Todo App 專案起步  
2. [**Git**](/docs/week3/git)：版本控制概念與常用指令  
3. [**分支策略**](/docs/week3/branch-strategy)：Git Flow 範例、分支命名、merge／rebase 與 PR 演練  
4. [**GitHub**](/docs/week3/github)：遠端協作、Fork、Pull Request（**CI／GitHub Actions 見第十一週**）

### 學習目標

- 理解版本控制的目的與 Git 基本模型（commit、branch、merge）。  
- 能獨立完成 clone、branch、commit、push、pull 與處理簡單衝突。  
- 熟悉 GitHub 上议题、分支策略與 Code Review 的協作節奏。
