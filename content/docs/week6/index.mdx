## 第六週：Container（Docker、Docker Compose）與雲端原生

本週在第三週版控與 GitHub 協作的基礎上，深入**容器化**與**多服務編排**：從 Docker 映像與 Dockerfile 出發，學習 Registry、Docker Compose 多容器協作，並簡介雲端原生思維與透過 SSH 部署的實務。

關於第三週的重點複習，請參考[第三週回顧](/docs/week6/review-week3)，以 Git / GitHub 指令與流程為主。

## 課程大綱

1. [**Docker 基礎與映像**](/docs/week6/docker)  
   - 映像與容器、Dockerfile 撰寫與本機建置執行

2. [**Docker 進階：Registry**](/docs/week6/docker-registry)  
   - Docker Hub / Registry、標籤與推送映像

3. [**Docker Compose 與多服務協作**](/docs/week6/docker-compose)  
   - `docker-compose.yml`、多服務（例如前端 + 後端 + 資料庫）

4. [**Docker Swarm 與 Stack**](/docs/week6/docker-swarm)（選讀／進階）  
   - 叢集、`docker stack deploy`、滾動更新

5. [**雲端原生簡介**](/docs/week6/cloud-native)  
   - 雲端原生原則、微服務與編排概念

6. [**SSH 與遠端部署**](/docs/week6/ssh-deploy)  
   - 金鑰、連線與部署流程

7. **課堂練習與討論**  
   - [常見問題與實作指引](/docs/week6/qa-discussion)

## 注意事項

- 實作建議預先準備 Docker Hub（或相容 Registry）帳號。  
- 遠端部署請注意埠號與環境變數，避免與他人衝突。
