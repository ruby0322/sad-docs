## 第十一週：DevOps（單元測試、Playwright、GitHub Actions）

本週以 **DevOps 實務**為主軸：建立測試計畫與策略，撰寫 **Jest** 單元測試與 **Playwright** 端對端測試，並透過 **GitHub Actions** 將測試與工作流程自動化，與第三週、第六週的版控與部署能力銜接。

4. [**E2E 測試（Playwright）**](/docs/week11/e2e-tests)  
5. [**GitHub Actions / CI**](/docs/week11/github)

## 學習目標

- 能說明測試金字塔與專案中各層測試的角色。  
- 能撰寫與維護單元測試與基本的 Playwright 情境。  
- 能設定簡單的 GitHub Actions workflow 在 push / PR 時執行測試。
